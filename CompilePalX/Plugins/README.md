Drop a plugin folder in here and Compile Pal picks it up at startup.

A plugin is a folder holding a `meta.json`, a `parameters.json` and whatever it runs. The format is
documented in [Guides/Plugins.md](https://github.com/catualus/CompilePal/blob/master/Guides/Plugins.md).

Use plugins at your own risk. A plugin is a program that runs on your machine as part of a compile,
so do not install one from a source you do not trust.
